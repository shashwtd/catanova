# Original artwork

These are the accepted PNG masters, moved unchanged out of the public download directory. Keep them for future exports so compression is never repeatedly applied to already compressed artwork. Their original generation hashes and provenance remain in `docs/art/`.

The website uses the WebP derivatives listed in [runtime-art.json](../../docs/art/runtime-art.json). These masters are excluded from the Docker build context and are never served by the game. See [runtime artwork](../../docs/art/RUNTIME.md) for export and validation instructions.
