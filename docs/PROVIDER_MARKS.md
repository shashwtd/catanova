# Provider marks

These third-party marks identify sign-in and repository links. They are not Catanova artwork and are not covered by the project's MIT grant. Their owners retain their trademark rights. All assets are served locally; displaying a provider mark makes no request to that provider.

## Google

- **Mark:** `apps/client/public/art/providers/google-g.png`, copied unchanged from [Google's official G asset](https://developers.google.com/static/identity/images/g-logo.png), linked by the [Sign in with Google branding guidelines](https://developers.google.com/identity/branding-guidelines). Retrieved 9 September 2026. Original dimensions: 200 × 204; RGBA PNG.
- **Presentation:** the current multicolor gradient G appears beside the sign-in or linking action on a white button. The image retains its aspect ratio, colors and artwork. The entry button matches the homepage's height, corner radius and warm raised edge while retaining its neutral provider face and Google Sans label.
- **Typeface:** `apps/client/public/fonts/google-sans-medium-latin.woff2`, the unmodified Latin subset for Google Sans Medium, obtained through the [official Google Fonts stylesheet](https://fonts.googleapis.com/css2?family=Google+Sans:wght@500&display=swap). It is used only for the Google button. [Exact downloaded font](https://fonts.gstatic.com/s/googlesans/v70/4Ua_rENHsxJlGDuGo1OIlJfC6l_24rlCK1Yo_Iqcsih3SAyH6cAwhX9RFD48TE63OOYKtrw2IJllpynAFyo4R4o.woff2).
- **Font license:** SIL Open Font License 1.1. The [Google Sans source repository](https://github.com/googlefonts/googlesans) supplies its [OFL file](https://github.com/googlefonts/googlesans/blob/main/OFL.txt); an unchanged copy is bundled at `apps/client/public/licenses/google-sans-OFL.txt`. That upstream notice credits the Google Sans Flex Project Authors.

## GitHub

- **Mark:** `apps/client/public/art/providers/github-invertocat-white.svg`, copied unchanged from `GitHub Logos/SVG/GitHub_Invertocat_White.svg` in the [official logo bundle](https://brand.github.com/GitHub_Logos.zip). Retrieved 9 September 2026. Original view box: 98 × 96.
- **Guidance:** [GitHub's logo toolkit](https://brand.github.com/foundations/logo) permits using its mark to link to a GitHub project. Catanova uses the white mark beside an explicit GitHub repository link, at its original aspect ratio, without recoloring or visual effects.
- **Placement:** the footer uses a quiet, darkened backdrop for contrast. The mark remains secondary to Catanova's own identity and does not imply GitHub endorsement.
