# Painted UI icon atlas

Created using the built-in image generation tool. Shipping file: `apps/client/public/art/optimized/painted-icons.ca739109762c.webp`, 576×432 pixels, 93,816 bytes. Forty new icons and seven approved icons are packed into 72-pixel cells, with each image fitted into 64×64 and a four-pixel gutter. Cell mapping is in `apps/client/src/painted-icons.ts`.

Processing: crop each generated sheet into cells, trim transparent padding, fit each icon into 64×64, pack without changing the artwork, encode once to WebP quality 78 / effort 6. Alpha is preserved. SVG containers only crop the shared bitmap; this is not vector tracing. One cached file supplies every icon and is included in the game preloader. The superseded individual files were removed. No generated originals or extra dependencies are committed.

The seven prior images (road, house, city, trophy, purchase, road award, army award) use the prompt recorded in [Player awards](player-awards.md). Other icons use these prompts:

Each image must be an immediately readable icon at 32 pixels. Flat-ish sculptural paint, not 3D render. Actual alpha transparency. No labels or extra marks anywhere.

## September 13 control refinement

Trophies, inventory, earned awards, fullscreen, menu/close, leave-room, rules/help, trade, building and ready symbols retain the painted atlas. Settings, friends, editing, copy/link/share, refresh, history and simple navigation now use small native SVG paths in `GameIcons.tsx`, inheriting the surrounding text color. Dedicated join, sign-out, defeat and music symbols replace ambiguous reused icons. These controls add no image downloads. The source atlas remains available for existing painted symbols.
